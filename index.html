Overview

This laboratory module introduces students to the fundamental principles of process control using a temperature-controlled enclosure. Students will explore three control strategies — Manual, On/Off, and PID — and evaluate their performance through real-time data acquisition and analysis.

The Matrix Process Control Temperature Trainer provides a safe, bench-top environment for experimenting with heater power, fan speed, and feedback control algorithms used extensively in industrial applications such as chemical reactors, HVAC systems, and food processing equipment.

🎯 Learning Objectives

  • Understand open-loop vs closed-loop control
  • Operate manual, on/off, and PID controllers
  • Measure and interpret step response characteristics
  • Tune PID parameters using empirical methods
  • Evaluate control performance using error metrics

🔧 Equipment

  • Matrix PCT Temperature Trainer
  • USB HID interface cable
  • PC running this control software
  • Thermocouples (internal)
  • Heater element & fan assembly

⚠️ Safety Notes

  • Maximum operating temperature: 70°C
  • Do not block the air vents
  • Allow 5 min cool-down before handling
  • Report any unusual smells immediately
  • Keep liquids away from the unit

🧮 Control Theory

Manual (Open-Loop) Control

In manual control the operator sets heater power directly with no feedback from the measured temperature. The output does not adjust to disturbances or set-point changes. This mode is useful for understanding the open-loop gain and time constant of the process.

P_heater = constant (set by operator)
T_actual ≠ T_target (no correction)

On/Off (Bang-Bang) Control

The controller switches the heater fully ON when temperature falls below (setpoint − hysteresis/2) and fully OFF above (setpoint + hysteresis/2). Simple to implement but produces oscillation whose amplitude is determined by hysteresis.

IF T < (SP − H/2): P = 100%
IF T > (SP + H/2): P = 0%

PID (Proportional–Integral–Derivative) Control

PID control computes the control output as the sum of three terms acting on the error e(t) = SP − T(t). The Proportional term reacts to the current error. The Integral term eliminates steady-state offset. The Derivative term damps oscillations by reacting to the rate of change.

u(t) = Kp·e(t) + Ki·∫e(t)dt + Kd·(de/dt)

Kp = Proportional gain
Ki = Integral gain (= Kp / Ti)
Kd = Derivative gain (= Kp · Td)
Kp ↑
Faster response, more overshoot, can oscillate
Ki ↑
Eliminates offset, slower, risk of windup
Kd ↑
Reduces overshoot, sensitive to noise

🧪 Laboratory Procedure

  • Part A — System Familiarisation (15 min)
    Connect the unit via USB. Observe the live temperature and system status in the Main App. Set heater power to 20% in Manual mode and record the steady-state temperature after 5 minutes. Note fan speed effect by increasing fan from 0% to 50%.
  • Part B — Open-Loop Step Response (30 min)
    With the system at room temperature, apply a step from 0% to 50% heater power (Manual mode, fan at 30%). Use CSV export to record data. Identify the process gain K, time constant τ, and dead time θ from the response curve. Repeat for a 50%→100% step.
  • Part C — On/Off Control (20 min)
    Switch to On/Off mode. Set target to 45°C, hysteresis to 3°C. Allow the system to reach steady oscillation. Measure oscillation period and amplitude. Repeat with hysteresis at 1°C and 10°C. Record observations.
  • Part D — PID Control & Tuning (45 min)
    Switch to PID mode. Begin with P-only control (I=0, D=0). Gradually increase Kp until oscillation begins, then reduce by 50% — this is Kp_initial. Add integral (Ki = Kp/10Ti) to eliminate offset. Add derivative (Kd = Kp·Td/8) to reduce overshoot. Apply a setpoint step from 30°C to 50°C to evaluate final tuning.
  • Part E — Comparison & Report (30 min)
    Export all CSV data. Plot step responses for all three modes on a single graph. Calculate rise time, settling time, overshoot, and steady-state error for each. Complete the Results & Analysis worksheet.
Use the 💾 Save CSV button on the Main App chart to capture each experiment's data for later analysis.
